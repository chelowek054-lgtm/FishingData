# FishingData

Данные приложения «Пора на рыбалку / Time to Fish»: справочник видов и словари знаний.
Своего сервера у приложения нет — файлы читаются отсюда, из репозитория.

## Как это читает приложение

Адреса этих файлов зашиты в сборку приложения (`AppEndpoints`). Приложение обновляет
по ним справочник видов и словари знаний: новый вид или уточнённые параметры
приезжают без новой сборки. Без сети или при битом файле остаётся последняя копия,
а без неё — встроенная в `assets`.

**Конфига здесь больше нет** (с 2026-11-21). Раньше `config.json` задавал адрес приёма
выездов и выключатель сбора — то есть файл в репозитории мог включить отправку личных
данных у всех установок сразу. Теперь это решается только новой версией приложения.

## Состав

| Путь | Что это |
|---|---|
| `species/initial_fish.json` | справочник видов: оси, оптимумы, поведение |
| `knowledge/knowledge.json` | словари знаний по-русски: типы воды, структуры, способы, прикормка |
| `knowledge/knowledge_en.json` | те же словари по-английски |
| `privacy.md` | политика конфиденциальности приложения: ссылка для карточки RuStore |

## Правила

- **Файл — документ, а не настройка.** Меняется целиком, с новой версией внутри и записью в `CHANGELOG.md`.
- **Переименовывать и переносить файлы нельзя.** Их адреса зашиты в выпущенные версии приложения.
- **Ссылки — на `raw.githubusercontent.com`**, а не на страницы GitHub: приложению нужен файл, а не HTML.
