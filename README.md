# FishingData

Данные приложения «Пора на рыбалку / Time to Fish»: справочник видов, словари знаний
и конфигурация. Своего сервера у приложения нет — файлы читаются отсюда, из репозитория.

## Как это читает приложение

Приложение берёт `config.json` один раз за сессию, в фоне и только при наличии сети.
Если сеть недоступна или файл битый — остаётся последний скачанный конфиг, а без него —
встроенная копия в `assets`. По `ETag` неизменившийся файл не скачивается повторно.

По ссылкам из конфига приложение обновляет справочник видов и словари знаний:
новый вид или уточнённые параметры приезжают без новой сборки приложения.

## Состав

| Путь | Что это |
|---|---|
| `config.json` | ссылки на данные, адрес приёма выездов и выключатель сбора |
| `species/initial_fish.json` | справочник видов: оси, оптимумы, поведение |
| `knowledge/knowledge.json` | словари знаний по-русски: типы воды, структуры, способы, прикормка |
| `knowledge/knowledge_en.json` | те же словари по-английски |
| `schema/config.schema.json` | схема конфига, по ней приложение проверяет файл до применения |

## Правила

- **Файл — документ, а не настройка.** Меняется целиком, с новой версией внутри и записью в `CHANGELOG.md`.
- **`updatedAt` двигается при каждом изменении.** По нему видно, какой конфиг был у рыболова, когда он записал выезд.
- **`isDataCollect` — выключатель проекта, а не согласие.** Сбор идёт, только если включён и он, и переключатель у самого рыболова.
- **Ссылки — на `raw.githubusercontent.com`**, а не на страницы GitHub: приложению нужен файл, а не HTML.
